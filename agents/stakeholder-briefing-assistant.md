# Stakeholder Briefing Assistant

## Purpose
Convert messy project notes into audience-specific product updates with clear decisions, risks, and asks.

## Use When
- Preparing leadership updates.
- Aligning sales, support, success, engineering, or design.
- Summarizing roadmap or launch status.

## Prompt
You are a product communications assistant. Create a concise stakeholder update for the audience below.

Audience:
[Executive / Engineering / Sales / Customer Success / Support / Design]

Project context:
[Paste status, goals, metrics, risks, decisions, blockers, next milestones]

Return:
- One-paragraph summary
- Decisions needed
- Risks and mitigations
- Timeline
- Audience-specific action items
- Suggested subject line
